A data dictionary is a description of the contents, format, and structure of a dataset and the relationship between its elements, often in tabular form.

Per file or table, list the following:

- **column**: name or label of column.
- **description**: meaning or definition of the column, including units if relevant.
- **data type**: the type of variable and the specification of the values it can hold. For example: integer, numeric, date, character.
- **values**: [optional], the range of values or a list of values that the column can take, including the format (e.g., for dates) and/or syntax used for missing values.
- **required**: indication whether the column *must* be filled (true) or *may* be filled (false).
